# COSINUX
**Your Digital World, Simplified.**

Ce paquet contient la version web autonome du prototype COSINUX, rebrandée depuis le prototype UTILYX existant.

## Lancer le prototype
Ouvrir `index.html` dans un navigateur moderne.

## Contenu actuel
- Interface bilingue français / anglais
- Outils de conversion et de traitement de texte
- Génération d'identifiants et de mots de passe
- Traitement local dans le navigateur pour les fonctions disponibles

## Limites importantes
Ceci est un prototype front-end autonome. Il ne contient pas encore de serveur, de comptes utilisateurs, de base de données, de paiement, de tableau de bord administrateur connecté ni de passerelle IA. Ces composants devront être développés et testés avant une mise en production.
