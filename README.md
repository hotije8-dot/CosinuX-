# COSINUX v1

12 outils numériques qui tournent dans le navigateur, sans serveur. FR / EN. Installable sur Android (PWA).

Outils : JSON→CSV, CSV→JSON, Base64 (encoder/décoder), conversion d'image PNG/JPG/WebP, extraction d'e-mails / liens / téléphones, suppression des doublons, nettoyage de texte, UUID, mot de passe / SHA-256.

## Mise en ligne gratuite (GitHub Pages)
1. Dépôt GitHub : envoyer index.html, manifest.json, sw.js, icon.svg, README.md à la racine.
2. Settings → Pages → Source : « Deploy from a branch », branche main, dossier / (root).
3. Le site est disponible à https://<utilisateur>.github.io/<dépôt>/
